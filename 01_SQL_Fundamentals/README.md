# 📊 Guía de Estudio SQL para Análisis de Datos

Bienvenido a mi repositorio de aprendizaje continuo. Como analista de datos, creo firmemente en aprender construyendo y documentando. Aquí estructuro mi dominio de SQL, desde los fundamentos hasta consultas relacionales complejas, con notas teóricas y scripts aplicados a casos de uso.

## 🗂️ Índice del Contenido

### [01. Teoría Básica]
* Conceptos de Bases de Datos Relacionales.
* Entidades, Atributos y Claves (Primary & Foreign Keys).

### [02. DDL - Creación de Base de Datos]
* `CREATE DATABASE` y `CREATE TABLE`.
* Tipos de Datos (`VARCHAR`, `INT`, `DECIMAL`, `DATE`).
* Importación masiva de archivos `.csv` (BULK INSERT).

### [03. DML - Manipulación y Filtros Básicos]
* Operaciones CRUD (`INSERT`, `UPDATE`, `DELETE`).
* El comando `SELECT` y el uso de alias (`AS`).
* Filtros avanzados con `WHERE`, `IN`, `BETWEEN` y `LIKE`.

### [04. Agrupaciones y Resúmenes]
* Funciones de Agregación (`SUM`, `COUNT`, `AVG`).
* Agrupación de datos con `GROUP BY`.
* Filtro de grupos con `HAVING` vs `WHERE`.
* Ordenamiento de reportes con `ORDER BY`.

### [05. Relaciones y JOINS]
* Normalización y cruce de datos.
* `INNER JOIN`: Intersecciones perfectas.
* `LEFT JOIN` y manejo de valores `NULL` para auditoría de datos.
