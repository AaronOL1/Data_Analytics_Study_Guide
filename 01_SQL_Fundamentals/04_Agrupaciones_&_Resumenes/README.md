# 📁 Módulo 04: Agrupaciones y Resúmenes (Group By & Having)

En este módulo pasamos de analizar filas individuales a generar verdaderos resúmenes de negocio. Aquí es donde los datos empiezan a responder preguntas estratégicas.

### 📝 Contenido del Módulo

* **Clase 05: Funciones de Agregación y GROUP BY.**
    * Uso de `SUM()`, `AVG()`, `COUNT()`, `MAX()`, `MIN()`.
    * Cómo agrupar categorías para obtener totales segmentados (ej. Ventas por Ciudad, Ingresos por Línea de Producto).
* **Clase 06: Filtrando Grupos (HAVING) y Ordenando (ORDER BY).**
    * La diferencia técnica y lógica entre `WHERE` (filtra filas antes del cálculo) y `HAVING` (filtra grupos después del cálculo).
    * Cómo ordenar los resultados para crear listados de "Top N" o rankear categorías.

### 🎯 Objetivo de Negocio
Aprender a reducir bases de datos de miles de registros a tablas resumen concisas que la directiva pueda leer rápidamente para la toma de decisiones.
