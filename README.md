## 🗺️ Mapa del Conocimiento (Estructura)

El repositorio está organizado por tecnologías y niveles de dificultad:

### 🗄️ [01_Dominio_SQL](./01_Dominio_SQL)
*Desde la sintaxis básica hasta la lógica de negocio compleja.*
Aquí recopilo lo aprendido durante mi formación académica (CEC-EPN) y el certificado profesional de Google.
* **Básicos:** Estructura `SELECT`, filtrado `WHERE` y ordenamiento.
* **Intermedio:** El arte de los `JOINS` (explicado gráficamente) y Agregaciones (`GROUP BY`).
* **Avanzado:** Common Table Expressions (CTEs), Subconsultas y Funciones de Ventana.
* *Incluye ejercicios prácticos y scripts comentados línea por línea.*

### 📊 [02_PowerBI_PL300](./02_PowerBI_PL300)
*Camino a la certificación oficial: Microsoft Power BI Data Analyst.*
Documentación de mi proceso de estudio para el examen PL-300.
* **Preparación de Datos:** Power Query y limpieza (ETL).
* **Modelado de Datos:** La joya de la corona. Entendiendo el **Esquema en Estrella** (Star Schema) y Cardinalidad.
* **DAX:** Fórmulas esenciales (`CALCULATE`, `FILTER`) explicadas con lógica, no de memoria.
* **Visualización:** Principios de diseño y narración de datos (Storytelling).

## 🧠 Filosofía de Estudio

En este repositorio no solo encontrarás código, sino el **"Por qué"**.
Creo firmemente que un analista no se define por memorizar sintaxis, sino por su capacidad de resolver problemas.

> *"No aprendas la herramienta, aprende el concepto. La herramienta cambia, la lógica permanece."*
